# مشروع سبا - موقع إلكتروني متكامل للسبا والعناية بالجمال

## مرحباً بك في سبا! 🌸

موقع إلكتروني احترافي لمشروع سبا يقدم خدمات متنوعة في مجال الاسترخاء والعناية بالجمال، مع نظام تسجيل دخول آمن وقاعدة بيانات متقدمة.

## خطوات التثبيت والتشغيل

### 1. تحضير المشروع

```bash
# استخرج ملف المشروع المضغوط
unzip spa-project.zip

# انسخ مجلد المشروع إلى مجلد htdocs في XAMPP
cp -r mystery-box-spa C:/xampp/htdocs/
# أو على Linux/Mac:
cp -r mystery-box-spa /opt/lampp/htdocs/
```

### 2. تشغيل XAMPP

- افتح لوحة تحكم XAMPP
- ابدأ خدمة **Apache**
- ابدأ خدمة **MySQL**

### 3. إنشاء قاعدة البيانات

#### الطريقة الأولى: استخدام phpMyAdmin

1. افتح `http://localhost/phpmyadmin/`
2. انقر على **"استيراد"** (Import)
3. اختر ملف `database/spa_db.sql` من مجلد المشروع
4. انقر على **"تنفيذ"** (Execute)

#### الطريقة الثانية: استخدام سطر الأوامر

```bash
# على Windows
mysql -u root < C:\xampp\htdocs\mystery-box-spa\database\spa_db.sql

# على Linux/Mac
mysql -u root < /opt/lampp/htdocs/mystery-box-spa/database/spa_db.sql
```

### 4. الوصول إلى الموقع

افتح متصفحك وانتقل إلى:
```
http://localhost/mystery-box-spa/login.html
```

### 5. تسجيل الدخول

استخدم بيانات الاختبار التالية:

**حساب المسؤول:**
- اسم المستخدم: `admin`
- كلمة المرور: `123456`

**حساب تجريبي:**
- اسم المستخدم: `user`
- كلمة المرور: `password`

## جداول قاعدة البيانات

### جدول المستخدمين (users)
- `id`: معرف فريد للمستخدم
- `username`: اسم المستخدم (فريد)
- `password`: كلمة المرور المشفرة
- `email`: البريد الإلكتروني
- `full_name`: الاسم الكامل
- `phone`: رقم الهاتف
- `status`: حالة الحساب (نشط/غير نشط/محظور)
- `created_at`: تاريخ الإنشاء
- `last_login`: آخر تسجيل دخول

### جدول الحجوزات (bookings)
- تخزين حجوزات الخدمات
- ربط بجدول المستخدمين
- تتبع حالة الحجز

### جدول المنتجات (products)
- معلومات المنتجات والأسعار
- الفئات والمخزون
- الصور والأوصاف

### جداول أخرى
- `orders`: الطلبات
- `order_items`: تفاصيل الطلبات
- `reviews`: التقييمات والآراء

## الميزات الأمنية

🔒 **تشفير كلمات المرور**
- استخدام `password_hash()` و `password_verify()` (bcrypt)
- تشفير قوي وآمن

🛡️ **الحماية من الهجمات**
- استخدام Prepared Statements لمنع SQL Injection
- التحقق من صحة البيانات المدخلة
- تسجيل محاولات تسجيل الدخول الفاشلة

📋 **إدارة الجلسات**
- جلسات آمنة للمستخدمين المسجلين
- ملفات تعريف الارتباط الآمنة مع الخيار httponly
- تحديث وقت آخر تسجيل دخول

## استكشاف الأخطاء

### المشكلة: "خطأ في الاتصال بقاعدة البيانات"

**الحل:**
1. تأكد من أن خدمة MySQL تعمل
2. تأكد من أن قاعدة البيانات `spa_db` موجودة
3. تحقق من بيانات الاتصال في `php/login.php`:
   - `servername`: localhost
   - `db_username`: root
   - `db_password`: (فارغ بشكل افتراضي)
   - `dbname`: spa_db

### المشكلة: "اسم المستخدم أو كلمة المرور غير صحيحة"

**الحل:**
1. تأكد من أنك تستخدم البيانات الصحيحة:
   - admin / 123456
   - user / password
2. تحقق من أن الحساب نشط (status = 'active')
3. تحقق من سجلات الأخطاء في `error_log`

### المشكلة: الصور لا تظهر

**الحل:**
1. تأكد من أن مجلد `images/` موجود
2. تحقق من أسماء الملفات والمسارات
3. تأكد من أن الصور موجودة في المجلد

### المشكلة: لا يتم التحويل إلى الصفحة الرئيسية بعد تسجيل الدخول

**الحل:**
1. افتح وحدة التحكم في المتصفح (F12)
2. تحقق من رسائل الخطأ في Console
3. تأكد من أن ملفات PHP موجودة في مجلد `php/`
4. تحقق من أن JavaScript مفعل في المتصفح
